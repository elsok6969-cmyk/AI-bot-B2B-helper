Mynota — почти готово

В базе ещё нет ни одного менеджера, поэтому дашборд пуст. Чтобы тебя создало в БД — отправь /start боту в Telegram. Достаточно одного сообщения; после этого вернись и обнови страницу.

Что нужно проверить

  • BOT_TOKEN и OWNER_TELEGRAM_ID в .env — без них бот не запустится.
  • Бот должен висеть в Telegram (логи: docker compose logs -f app).
  • Ты должен отправить ему /start хотя бы один раз с того аккаунта, чей TG ID — OWNER_TELEGRAM_ID.

После /start доступны

  • / — дашборд
  • /clients — клиенты
  • /telethon — подключить личный ТГ-аккаунт
  • /mail — подключить Яндекс.Почту
